Capybara & Friends 是一个独立研究机构。

## 研究理念

探索本质，连接思想，创造影响。我们相信，好的研究不只是在答案出现时才有价值，也应该让问题、路径和限制都能够被别人看见。

## 工作方式

我们以小规模、可复现的实验为起点，把阅读、实现、测量与写作放在同一条工作流里。研究笔记会随着实验更新，结论也允许保留不确定性。

## 联系方式

如果你正在思考相近的问题，欢迎通过 GitHub 与我们交流。公开内容会持续整理到研究档案中。
